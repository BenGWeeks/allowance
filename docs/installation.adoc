= Installing Allowance

== Requirements

Allowance requires LNbits 1.6.0 or later in the tested 1.6.x series, SQLite or PostgreSQL, and a configured LNbits funding source. Use the Python version supported by your LNbits release. This is a native Python extension with server access, not a sandboxed WASM extension.

== Install

. Add `https://raw.githubusercontent.com/BenGWeeks/allowance/main/extensions.json` under Server → Extension Sources.
. Install the latest stable Allowance release from Extensions.
. Activate it on the server and enable it for your user.
. Open Allowance and select a source wallet you own when creating an allowance.

Allowance is not yet vetted for the official LNbits registry. The custom source lists released archives and their SHA256 hashes.

== Upgrade

. Back up the LNbits databases and installed extension files. Record activation and next-payment dates.
. Check for pending or uncertain payments before maintenance; reconcile these before proceeding.
. Deactivate Allowance, install the new release, then restart LNbits to load its Python modules.
. Restore activation and check the scheduler, history and next-payment dates.
. Hard-refresh the browser if it still shows the previous interface.

An overdue allowance may attempt one payment when scheduling resumes. An upgrade does not replay every missed interval. If missed occurrences should be skipped, the operator must handle that before reactivating the scheduler. The UI has no bulk skip control.

Environment changes require recreating the container; restarting alone does not load new Docker environment values. Preserve data volumes and extension installation files when recreating it.

== Recipient networking

Recipients must use HTTPS on port 443 and resolve to allowed public addresses. Split DNS can resolve an otherwise public hostname to a private IP inside the LNbits container. The operator can configure exact trusted hostname/private IPv4 pairs using `ALLOWANCE_TRUSTED_LNURL_DESTINATIONS`. See link:../README.md#lnurl-network-policy[the network policy] for accepted addresses, certificate checks and callback handling. Verify HTTPS metadata without requesting an invoice before enabling payments.

== Development

See link:../README.md#development-and-testing[development setup] and link:testing.adoc[testing]. The source bind mount is intended for development; use disposable containers to test native archive installation.

== Failed 1.1.0 installation

Do not install the withdrawn 1.1.0 release. Restore the previous extension files and restart LNbits before installing a repaired stable release. Consult link:../README.md[the README recovery guidance] and preserve the database; uninstalling or deleting it is not a migration repair.
