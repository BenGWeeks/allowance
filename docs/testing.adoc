= Testing Guide
:toc:
:toc-placement: preamble
:toclevels: 3

Comprehensive guide for testing the LNBits Allowance extension.

== Overview

The Allowance extension includes extensive test suites:

* **UI Tests** - Playwright browser automation tests
* **API Tests** - Python-based endpoint testing
* **Integration Tests** - End-to-end workflow validation

== Test Environment Setup

=== Prerequisites

Install required dependencies:

[source,bash]
----
# System packages (Ubuntu/Debian)
sudo apt install python3-httpx python3-pytest python3-loguru nodejs npm

# Node packages (for UI tests)
npm install playwright
npx playwright install chromium
----

=== Configuration

Create `.env.local` with test credentials:

[source,bash]
----
TEST_LNBITS_URL=http://localhost:5001
LNBITS_ADMIN_USERNAME=testuser
LNBITS_ADMIN_PASSWORD=testpass123
RECEIVING_WALLET_NAME=TestReceiving
PAYLINK_EMAIL=test@example.com
----

IMPORTANT: Never commit `.env.local` to version control!

==== Writing New UI Tests

Template for new UI test:

[source,javascript]
----
const { chromium } = require('playwright');
const { getConfig, login } = require('./auth-helper');

async function testFeature() {
  const browser = await chromium.launch({ headless: true });
  const page = await browser.newPage();
  const { baseUrl } = getConfig();

  try {
    // Login
    await login(page);

    // Navigate to extension
    await page.goto(`${baseUrl}/allowance`);

    // Your test logic here

    console.log('✅ Test passed!');
    process.exit(0);
  } catch (error) {
    console.error('❌ Test failed:', error);
    await page.screenshot({ path: 'test-screenshots/error.png' });
    process.exit(1);
  } finally {
    await browser.close();
  }
}

testFeature();
----

==== Writing New API Tests

Template for new API test:

[source,python]
----
import httpx
import json
from datetime import datetime, timedelta

BASE_URL = "http://localhost:5001"
API_KEY = "your-admin-key"

def test_feature():
    """Test description"""

    # Setup
    headers = {"X-Api-Key": API_KEY}

    # Make request
    response = httpx.post(
        f"{BASE_URL}/allowance/api/v1/endpoint",
        headers=headers,
        json={"key": "value"}
    )

    # Assertions
    assert response.status_code == 200
    data = response.json()
    assert data["success"] == True

    print("✅ Test passed!")

if __name__ == "__main__":
    test_feature()
----

== Continuous Integration

=== GitHub Actions Setup

Create `.github/workflows/test.yml`:

[source,yaml]
----
name: Test Suite

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Setup Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.9'

    - name: Install dependencies
      run: |
        pip install httpx pytest
        npm install playwright

    - name: Run API tests
      run: python -m pytest tests/api/

    - name: Run UI tests
      run: npm test
----

=== Pre-commit Hooks

Setup automatic testing before commits:

[source,bash]
----
# Install pre-commit
pip install pre-commit

# Create .pre-commit-config.yaml
cat > .pre-commit-config.yaml << EOF
repos:
  - repo: local
    hooks:
      - id: tests
        name: Run tests
        entry: ./tests/run_all_tests.sh
        language: system
        pass_filenames: false
EOF

# Install hooks
pre-commit install
----

== Performance Testing

=== Load Testing

Test with many allowances:

[source,python]
----
import httpx
import time

def load_test(count=100):
    """Create many allowances"""
    start = time.time()

    for i in range(count):
        response = httpx.post(
            f"{BASE_URL}/allowance/api/v1/allowance",
            headers=headers,
            json={
                "name": f"Load Test {i}",
                "lightning_address": "test@getalby.com",
                "amount": 1,
                "frequency_type": "yearly"
            }
        )
        assert response.status_code == 201

    elapsed = time.time() - start
    print(f"Created {count} allowances in {elapsed:.2f}s")
    print(f"Average: {elapsed/count:.3f}s per allowance")
----

== Best Practices

. **Always use test wallets** - Never test on production wallets
. **Clean up test data** - Delete test allowances after tests
. **Use meaningful names** - Include "TEST" in allowance names
. **Test incrementally** - Build tests step by step
. **Document failures** - Screenshot and log errors
. **Version your tests** - Keep tests in sync with code
. **Test edge cases** - Don't just test happy paths
. **Monitor resources** - Check CPU/memory during tests

== Troubleshooting Test Failures

Common issues and solutions:

[cols="1,2", options="header"]
|===
|Issue |Solution

|Login fails
|Check credentials in .env.local

|Element not found
|UI may have changed, update selectors

|API returns 404
|Check endpoint URL and method

|Timeout errors
|Increase timeout or add waits

|Permission denied
|Check API key permissions

|Database errors
|Reset database or clean test data
|===

For more help, see link:troubleshooting.adoc[Troubleshooting Guide].
